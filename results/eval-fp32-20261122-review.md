B1 减 B0 的执行方区间上界为 +28.93 pp，本次明确指定的重采样实现复算为 +29.56 pp。Proposal 或展示引用时请使用同一实现，并随数值保留种子及重采样说明。两个种子内 OP 减 TG 的满分率区间都跨 0。TG 与 B1 的满分总数相同，每个种子各有 20 个任务的满分状态不同。

按终局任务奖励复算，OP 减 TG 的均值差在 seed 42 为 −0.00933（95% 区间 −0.03983 至 +0.02107），在 seed 43 为 −0.01426（−0.04277 至 +0.01373）。直接使用 seed 43 原始 `final_reward` 会得到 −0.00734，与包内配对摘要一致。汇报终局奖励时采用前者的未购买归零口径。

## 训练记录与动作案例

- 16 轮训练摘要与 meta 的任务 ID 和 run ID 一致。每轮均用冻结 train 的 4 个任务，train/val/test 互斥。四条链各 4 次更新，actor/critic 更新前后摘要变化，后续轮的起点摘要和父 run ID 接上本臂前一轮。总计 64 个训练回合、272 个决策、220 次实际 `/step`、16,128 生成 token。证据核对范围为日志和摘要。
- 任务 10336 在 seed 42 的 TG 满分，在 OP 达到步数上限。OP 打开评论后点击当页不可用的购买按钮，随后六次未通过动作格式解析。
- 任务 4399 在 B1 满分，在两个 TG 种子中均达到步数上限。TG 在详情页重复尝试不可用的购买按钮，随后编造支付流程动作。只要保留了相同的满分总数，这类互换案例仍会出现在逐任务对照中。
- 任务 6700 的技术中断记录单列。隔离复现中重置返回成功，动作请求超过 180 秒后超时。该任务未计入六组的策略成败。
