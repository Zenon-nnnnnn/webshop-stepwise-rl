## E1：优势如何改变动作概率

先把选择简化为两个动作。已选动作概率 p=0.2，用一个 logit z 表示：p=sigmoid(z)，初始 z=log(0.2/0.8)。固定样本优势 A，最大化目标 A log(p)。

对 z 的梯度是 A(1-p)，学习率取 0.1，做一次梯度上升：z_new=z+0.1 A(1-p)。

| 优势 | logit 梯度 | 更新后概率 |
|---|---:|---:|
| +0.3 | +0.24 | 0.20386766 |
| -0.3 | -0.24 | 0.19618763 |
| 0 | 0 | 0.2 |

这说明正优势推动已选动作概率上升，负优势推动下降。这里不是直接把优势加到概率上；更新的是参数，再由参数算概率。实际 LLM 是多 token、多样本和共享参数，PPO 还有 clipping、KL 等项，不能把这个单参数例子当作完整更新结果。

## E2：GAE 用后续误差估计优势

三步奖励 r=[0.1,0.3,0.4]，各步动作前的价值估计 V=[0.5,0.4,0.2]。最后是任务真正结束，末端 V=0；gamma=0.9，lambda=0.95。这些值均为教学假设。

先算 TD 残差：delta_t=r_t+gamma V(s_next)-V(s_t)。

- 第 1 步：0.1+0.9×0.4-0.5=-0.04。
- 第 2 步：0.3+0.9×0.2-0.4=0.08。
- 第 3 步：0.4+0-0.2=0.2。

从最后向前算 GAE：A_t=delta_t+gamma×lambda×A_next，终点后的 A=0。

- A_3=0.2。
- A_2=0.08+0.855×0.2=0.251。
- A_1=-0.04+0.855×0.251=0.174605。

第 1 步局部 TD 残差虽然为负，但合并后续残差后的 GAE 为正。它说明估计优势会利用后续结果，不能只看当前一步奖励或单个残差。它不证明任何动作的因果贡献。lambda 控制后续残差纳入的程度；gamma 控制未来奖励的折扣。

本例价值回归目标 A+V 为 [0.674605,0.651,0.4]。这是 lambda-return 形式的目标，不等同于未折扣奖励总和，也不应直接把它说成已观测的真实回报。

## CPU 复现

仓库根目录运行下列 Python（仅打印，不修改数据）：

```python
import math
p = 0.2
z = math.log(p / (1 - p))
for advantage in [0.3, -0.3, 0.0]:
    new_z = z + 0.1 * advantage * (1 - p)
    print(advantage, 1 / (1 + math.exp(-new_z)))
r, values = [0.1, 0.3, 0.4], [0.5, 0.4, 0.2, 0.0]
gamma, lam = 0.9, 0.95
deltas = [r[t] + gamma * values[t + 1] - values[t] for t in range(3)]
advantages = [0.0] * 3
following = 0.0
for t in reversed(range(3)):
    following = deltas[t] + gamma * lam * following
    advantages[t] = following
print(deltas, advantages)
```
