# 实验评审包：run ID

## 研究问题和实验类型

是 smoke、开发 val、进度预测验证、正式训练还是最终 test？计划检验什么？

## 可追溯信息

Git commit、实际命令、配置、基础模型 revision、初始化 checkpoint、运行环境、seed、数据/划分 SHA、goal fingerprint、日志与权重位置。

## 数据与预算

实际任务/轨迹/环境步数/生成 tokens/更新步数、训练与验证隔离、失败和中断清单。对照组哪些变量相同，哪些不同？

## RL 额外证据（涉及更新时填写）

采样策略及概率定义；动作/token mask；奖励向量与 grounding；return/advantage；PPO 的 old/ref policy、ratio、clip、KL、value；梯度与 adapter 更新；保存重载；更新后新采样。

## 原始结果与核算

原始表、任务清单、分母、统计脚本、区间/种子差异、代表性失败。小样本 smoke 不作性能结论。

## 解释与限制

结果是否回答研究问题？哪些其他解释仍可能存在？负结果与偏离协议的地方是什么？

## 独立验收

检查人、实际检查项、发现问题、通过/需修复；不能只有作者本人宣布通过。
